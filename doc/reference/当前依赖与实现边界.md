# 当前依赖与实现边界

适用于 Hub 0.7.0；安装约束以根目录 `pyproject.toml`、锁定开发环境以 `uv.lock` 为准。历史候选版本、npm 元数据和 R0/R1 研究不能作为当前运行要求。

| 范围 | 当前事实与依据 |
| --- | --- |
| Python | 3.14.x；[Python 官方文档](https://docs.python.org/3.14/)说明语言和运行库 |
| HTTP/WS | FastAPI、Uvicorn、websockets；单 ASGI worker，资源路由在当前进程；[Uvicorn 配置](https://www.uvicorn.org/settings/) |
| 数据库 | aiosqlite + SQLite schema 4；[SQLite WAL](https://www.sqlite.org/wal.html)；不支持多个 Hub 实例共享活动连接 |
| 启动配置 | PyYAML 安全读取 YAML，Pydantic 校验；[参数详解](参数详解.md)定义默认值与路径规则 |
| MCP | 可选 `mcp==2.3.0`，Streamable HTTP；公开 27 项项目工具，浏览器执行转给 Node |
| 浏览器 | Hub 和普通 HTTP 调用方不安装 Playwright、Node.js 或浏览器；33 项方法是项目自己的版本化合同 |
| 版本关系 | 管理 HTTP `/v1`、执行协议 2、playwright 工具 API 1、画面协议 1；各自独立，不靠路径前缀推断所有字段 |

公开行为以[工具调用协议](工具调用协议.md)、[方法表](Playwright方法表.md)、[画面合同](浏览器画面流接口.md)和[当前架构](../architecture/代码结构与执行流程.md)为准。官方库支持某方法，不代表本项目自动开放该方法；不支持官方 SDK 直连、任意脚本、SDK 回调或透明对象代理。

发布隔离验收见[Python 工具执行验收](../project/Python工具执行验收记录.md)，日常环境升级另有独立记录，不把旧测试成绩当作当前部署证明。测试覆盖 macOS 与 Ubuntu ARM64 的已列场景，不构成容量、所有浏览器/系统或窗口状态的承诺。原始研究来源见[历史依据](公开依据与研究边界.md)，其日期与结论保持历史含义。
