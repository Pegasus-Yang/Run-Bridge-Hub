# Hub 对外接口总览

当前 Hub 0.9.2 提供以下接口，兼容 Node 0.8.1：

- `/v1` 管理：设备登记；Hub认证查询资源池与领取Node；原租约令牌查询、续租、释放及检查节点能力。见[租约合同](Node使用权租约接口.md)。
- `/v2` 执行：项目工具目录、会话、方法调用、请求结果。详见[完整合同](工具调用协议.md)。
- `/v1/.../visual`：画面上传、目录/选择、观察订阅；独立于动作通道。
- `/dashboard`：默认开启的只读节点总览；`/dashboard/api/nodes` 使用独立只读 Bearer 口令，返回真实连接、资源、能力和控制通道 RTT。配置、开关和访问链接见[节点总览](../user-guide/节点总览.md)。

MCP 可选挂载 `/mcp`，参数见[Agent 手册](../user-guide/MCP浏览器接入.md)。浏览器对象只在 Node，Hub 不向外提供官方 SDK 连接或任意 Python 代码执行。
