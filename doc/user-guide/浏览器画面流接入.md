# 浏览器画面流接入

简体中文 · [English](浏览器画面流接入.en.md)

使用已交付的 access.json 创建工具会话，并执行第一条命令使其 ACTIVE，查询 `GET /v2/sessions/{id}`。响应的 visual.supported 表示该会话支持观察；使用返回的 stream_path，不自己猜 Node 或浏览器地址。

managed 图片来自 Node 同一个 Python Page；target_id 就是动作使用的 page_id。borrowed 使用可选采集扩展并映射为本会话 Page 引用。两种模式复用 runbridge-visual-v1，不要求调用方安装浏览器库。

Python 客户端见[画面流订阅.py](../reference/examples/画面流订阅.py)，需要在同一调用方环境安装 `httpx` 与 `websockets`。将脚本和真实访问文件保存到调用目录，在已有 `.venv` 中执行：

```bash
uv pip install --python .venv/bin/python 'httpx>=0.28,<1' 'websockets>=15,<18' -i http://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
.venv/bin/python 画面流订阅.py --access-file access.json --session-id session_example --frame-count 3
```

`session_example` 换成原调用创建并保持 ACTIVE 的真实会话 ID；脚本默认将有限帧保存到 `.runbridge/visual-frames`，不会创建或关闭浏览器会话。HTML 查看器见[画面查看示例.html](../reference/examples/画面查看示例.html)，使用访问文件中的实际基址和许可；浏览器 WebSocket 不能设自定义头时，先连接 stream_path，再发送首条 auth 消息。令牌不放查询字符串。

先处理状态消息，只有 LIVE 且新鲜图片才展示。目标目录由 visual.targets 返回，选择通过对应 target 接口；多页不猜第一个。画面过期、会话结束、许可撤销或失联后撤下旧图，不把旧截图持续显示成在线状态。

帧格式、限制和选择确认详见[画面合同](../reference/浏览器画面流接口.md)。画面只观察，不提供鼠标键盘远控；实际操作继续走项目 HTTP/MCP，并读取最终业务结果。
