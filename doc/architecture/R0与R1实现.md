# 节点管理与控制生命周期

Hub 0.9.3 保留 `/v1` 的节点登记、访问许可和能力查询：登记令牌接纳节点；身份令牌仅认证设备控制/执行/上传连接；访问令牌只授权调用方访问被许可节点和资源。另有Hub申请凭据只用于领取整Node租约；各类凭据不能互换。

稳定身份与连接代次分开。每次控制连接为 `/v2/nodes/{node_id}/control`，新连接递增 connection_generation 并替换旧连接；旧连接的确认和退出不能覆盖新连接状态。心跳超时将节点视为离线，能力报告带 observed_at 和 stale 状态。

资源的工具、方法列表、readiness 与 occupancy 由 Node 实际探测上报。Hub 保留会话独占预留，不能因为普通能力心跳声称 FREE 就释放仍在活动的会话。执行合同与对象目录见[会话架构](Playwright执行与会话管理.md)。
