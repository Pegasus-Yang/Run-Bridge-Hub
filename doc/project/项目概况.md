# 项目概况

当前 runbridge-hub 0.8.0 使用项目工具指令协议 2，兼容 Node 0.7.0。Hub 管理鉴权、资源、路由和请求状态；Node 的 Python worker 持有工具对象并执行操作。当前实现 playwright 工具 API 1，保留原有浏览器功能并移除官方 SDK 隧道依赖。

部署和操作以[文档导航](../README.md)列出的当前手册为准。0.5.x 及更早验收是历史事实，不证明新版本已经部署在任何旧测试环境。

Hub 同端口默认提供只读节点总览，显示实际连接、资源预留与占用、支持能力、最近心跳及 WebSocket Ping/Pong 实测 RTT；启动日志给出带独立只读口令的完整访问链接。页面随 Hub 安装包交付，支持配置关闭，不要求 Node 升版或额外部署前端。使用入口见[节点总览](../user-guide/节点总览.md)，版本变化见[更新日志](版本发布记录.md)。
