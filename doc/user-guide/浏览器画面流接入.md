# Hub 浏览器画面流接入

[文档导航](../README.md) · [调用方环境](调用方对接与使用.md) · [接口合同](../reference/浏览器画面流接口.md)

本指南只说明 Hub 0.5.1 对调用方提供的画面入口、订阅及展示。Node 所有者在自己的项目指南完成浏览器和采集准备；调用方无需安装采集器或操作远程设备的配置文件。

## 1. 接入前确认

| 场景 | 前置条件 |
| --- | --- |
| 已有 Chrome | 所有者已启用采集，资源就绪；调用方持有覆盖该资源的有效许可 |
| 受管理 MCP 页面 | 服务已提供 MCP，同一 MCP 页面声明画面能力 |
| 普通 SDK 受管理会话 | 当前无独立画面流，SDK 可自行截图 |

只有创建会话的同一许可可以查询和订阅该会话画面。ONLINE、supported 和入口存在分别说明不同状态，LIVE 由 Hub 收到新鲜有效帧确认。

按[调用方指南](调用方对接与使用.md)准备自己的 `.venv`、`examples/` 和私有 `access.json`；将[订阅脚本](../reference/examples/画面流订阅.py)复制到该目录。

## 2. 保持一个活动会话

已有 Chrome 的调用方，在自己的目录保持 SDK 连接：

```bash
.venv/bin/python examples/执行会话调用.py --access-file access.json --resource-id chrome --page-url 'https://your-test-system.example/account' --hold-seconds 60
```

替换实际资源和唯一匹配的已有页 URL，记录 ACTIVE 后输出的 session_id。只申请 READY 不会激活画面；执行示例不保持时会立即释放，随后订阅结束属于正常行为。MCP 画面则保持原 MCP 会话和页面，使用其返回的 session_id。

## 3. 订阅并保存 PNG

在调用方第二个终端，使用实际 session_id：

```bash
.venv/bin/python examples/画面流订阅.py --access-file access.json --session-id session_example --frame-count 3 --output-dir artifacts/visual-frames
```

脚本通过 Hub 查询状态、使用同一访问令牌订阅，先接收状态消息，再接收带元数据的 PNG。保存有限数量图片后退出，不关闭原生执行。图片保存在订阅者机器。

核对目标归属、递增 frame_id 和实际解码的图片；WebSocket 已连接或 PNG 签名正确都不是完整画面验收。

## 4. 明确选择画面来源

多页或原目标关闭时列出当前目标：

```bash
.venv/bin/python examples/画面流订阅.py --access-file access.json --session-id session_example --list-targets
```

已有 Chrome 的目标不公开真实 URL／标题。选择查询返回的真实 ID：

```bash
.venv/bin/python examples/画面流订阅.py --access-file access.json --session-id session_example --target-id target_example --frame-count 3
```

202／PENDING 只表示受理，后续等待 APPLIED／LIVE；同一会话同时只接受一个在途选择。选页只改变采集来源，不激活页面，也不改变实例授权范围。

受管理 MCP 的 target_id 是 page_id；通过 MCP browser_tabs 明确选页，同时切换同一页面的采集，不另建原生 SDK 连接。

## 5. 在调用方页面展示

将[画面查看页面](../reference/examples/画面查看示例.html)复制到自己的公开 `examples/`，只对该目录提供演示静态服务：

```bash
.venv/bin/python -m http.server 8000 --bind 127.0.0.1 --directory examples
```

在调用方本机打开 `http://127.0.0.1:8000/画面查看示例.html`。这里的服务仅展示调用方示例，不是本地部署 Hub／Node；访问文件保留在私有目录。

通过同一访问许可查询会话，取得 visual.stream_path，以 Hub 基址构造 WS／WSS 地址；在示例页填写入口和访问令牌。浏览器 WS 不能设置 Authorization 头，页面在连接后 5 秒内发送认证首消息。令牌不放进 URL 或静态源码。

保持原业务会话 ACTIVE，页面显示最新 PNG；断开订阅只停止查看。HTTPS 页面使用 WSS。Hub 没有通用 CORS 配置，HTTP 查询由调用方平台处理同源代理或自己的跨域设计。页面来源访问局域网还须符合实际浏览器权限策略。

## 6. 帧合同与状态

二进制消息为：

```text
4 字节大端 JSON 长度 + UTF-8 JSON 元数据 + PNG 字节
```

JSON 最多 4096 字节，PNG 最多 4 MiB；整条二进制消息不能直接作为 PNG 解码。官方 Playwright SDK 不处理这条独立封包。

展示只保留最新待绘制帧；选页变化或状态为 STALE／ERROR／WAITING_TARGET／STOPPED 时撤下旧图。5 秒没有有效新帧会 STALE，重连后须重新认证和查询当前来源。

| 状态／原因 | 调用方处理 |
| --- | --- |
| UNAVAILABLE／UNSUPPORTED_BACKEND | 核对资源路线与会话状态，联系所有者确认能力 |
| WAITING／WAITING_TARGET | 等待首帧或明确选择当前目标 |
| LIVE | 验证当前真实图片，不以声明替代实际内容 |
| ERROR／FRAME_TOO_LARGE | 撤图，读取错误；原 PNG 超 4 MiB 不自动缩放 |
| STOPPED | 会话已结束，新任务申请新会话 |
| 401／403 | 核对期限、撤销和创建该会话的许可归属 |

正常释放后确认 cleanup；采集状态不判断业务成功。中文方块由浏览器设备的所有者检查该用户的字体，Hub 服务器安装字体不会改变远端浏览器渲染。
