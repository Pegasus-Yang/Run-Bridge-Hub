## 0.8.0（2026-10-23）

新增默认开启的只读节点总览，Hub 与 Node 的执行合同保持兼容。本次 Hub 为 **0.8.0**，兼容 **Node 0.7.0**；本地附注 tag 为 `v0.8.0`。提交、tag 和打包均只在本地完成。

### 新增功能

- 同端口 `/dashboard` 展示真实节点列表、在线/准备中/离线状态、主机、版本、最近心跳、支持能力与资源占用。桌面和平板使用表格，手机使用分组列表；支持筛选、搜索和节点详情，每 5 秒刷新，断网时明确标记历史数据并自动重连。
- 资源统计复用 Hub 的连接和预留判断，正在准备会话或尚未确认清理的资源保持占用；准备中、离线、未知和未就绪资源不计为空闲。
- 控制通道 RTT 来自当前 WebSocket 的真实 Ping/Pong。连接后立即测量，随后沿用保活周期；样本超过 60 秒失效，断线清空，重连独立采样。不用心跳间隔或固定示例数值代替延迟。
- 总览使用独立只读口令。来源为 `web_token_file`、`RUNBRIDGE_WEB_TOKEN` 或数据库同目录自动生成/复用的 `web.token`；默认文件权限 `600`，不能复用登记令牌。`web_enabled: false` 或 `--disable-web` 同时关闭页面、静态资源和只读接口，并兼容可选 MCP 入口。
- 启动成功后，日志直接输出只读口令和已拼好 `token` 参数的完整 `Dashboard URL`。页面自动登录，刷新、收藏后可直接进入；退出或口令失效时清除参数。URL 使用实际监听端口，兼容 IPv6、通配地址和特殊字符编码；手动输入方式继续可用。
- HTML、CSS、JS 和附带 MIT 许可证的 Phosphor 图标随 wheel 安装，不新增端口、Node.js、前端构建步骤或 CDN 依赖。

### 升级与使用

执行协议仍为 2、playwright 工具 API 为 1、画面协议为 1，SQLite schema 4 和 Hub YAML 格式 1 均未变化。升级保留原数据库、登记文件、Node 身份和调用许可；Node 无需随 Hub 升版。首次启用总览会生成独立只读文件，见[升级说明](../deployment/运行与排障.md#从-070-升级到-081)。

README 功能介绍、快速开始、部署/排障、参数、节点总览、调用方/MCP、架构和开发打包手册已同步到 Hub 0.8.0 / Node 0.7.0。当前入口见[完整文档导航](../README.md)，历史设计与验收记录保留原日期和版本。

本地安装包为 `dist/runbridge_hub-0.8.0-py3-none-any.whl` 和 `dist/runbridge_hub-0.8.0.tar.gz`；构建与全新环境安装方法见[版本发布与本地打包](../development/版本发布与本地打包.md)。发布验证与私有机器的日常环境升级分别记录，不因本地包已生成就认定现有部署已升级。
