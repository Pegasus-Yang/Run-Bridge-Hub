# 管理与控制合同

适用于 Hub 0.9.1 / Node 0.8.1。此文给协议维护者使用，Node 所有者通过其项目 CLI 操作，无需手工发送下列消息。HTTP 管理路径版本为 1，节点控制消息版本为 2。

## HTTP 管理

所有秘密使用 `Authorization: Bearer <对应令牌>`，不放 URL。

| 完整路径 | 凭据与请求 | 结果 |
| --- | --- | --- |
| POST `/v1/nodes/register` | 登记令牌；JSON node_id、name、node_token | protocol_version=1、node_id、created；相同身份重试不覆盖原令牌 |
| GET `/v1/pool/nodes` 与 `/v1/pool/nodes/{node_id}/tools` | Hub申请令牌 | 查询节点、占用和与MCP同源的工具声明，不占用设备 |
| POST `/v1/nodes/{node_id}/grants` | Hub申请令牌；request_id必填、lease_seconds可选 | 整个Node独占租约，首次交付access_token及五字段access_config |
| GET / POST renew / DELETE `/v1/grants/{grant_id}` | 本租约access_token | 查询原状态、续租、幂等释放；到期后只允许原状态查询和重复释放 |
| GET `/v1/nodes/{node_id}` 或 `/capabilities` | 当前有效租约令牌 | 对应Node全部真实能力、新鲜度与本租约画面目录 |

旧Node所有者许可列表及撤销路径返回410，不提供管理旁路。领取具体输入、状态、严格整数期限及错误码见[Node使用权租约接口](Node使用权租约接口.md)。登记node_id/node_token由Node首次生成，Hub仅存摘要；身份令牌只认证设备连接。

## 控制 WebSocket

当前控制 WS 为 `/v2/nodes/{id}/control`，身份认证后 Hub 分配 connection_generation，所有控制消息 protocol_version=2。capabilities/heartbeat 及其 ack 维护新鲜度；session_open/prepared/stop/closed 管理会话。控制消息限制 64 KiB，上传与截图结果不能放入控制消息。

Node 使用身份令牌握手，Hub 返回例如：

```json
{"protocol_version":2,"type":"welcome","node_id":"node_example","connection_generation":3,"heartbeat_interval_seconds":30,"heartbeat_timeout_seconds":90}
```

后续消息使用本次 welcome 的代次，不读取历史 PID 或沿用旧连接代次。

| 方向与 type | 主要字段与含义 |
| --- | --- |
| Node → Hub：capabilities | connection_generation、capabilities；host/backends/resources 结构见查询样例，只报告实际探测结果 |
| Node → Hub：heartbeat | connection_generation；按 welcome 周期发送，不能靠浏览器动作流代替心跳 |
| Hub → Node：capabilities_ack / heartbeat_ack | connection_generation、observed_at、heartbeat_count |
| Hub → Node：session_open | connection_generation、session_id、resource_id、tool、tool_api_version |
| Node → Hub：session_prepared | connection_generation、session_id、runtime_version 或 error_code；对象目录先走执行连接并获确认 |
| Hub → Node：session_stop | connection_generation、session_id、reason |
| Node → Hub：session_closed | connection_generation、session_id、cleanup=COMPLETE/UNKNOWN，可带 error_code |
| Hub → Node：session_ack | connection_generation、session_id；确认 prepared/closed 报告 |
| Hub → Node：error | code；无效消息或身份/代次错误导致连接关闭 |

相同身份新建连接会替换旧连接。旧连接退出或迟到的消息不能覆盖新连接的状态。心跳超时关闭控制连接并使相关会话中断；资源是否可重新使用仍取决于实际清理确认。

实际工具参数、对象目录和动作结果走[项目执行协议](工具调用协议.md)的独立连接。旧 v1 控制连接退役，不能把管理路径版本与执行信封版本混同。
