# 管理与控制合同

管理 HTTP 路径保留 `/v1`，凭据格式未变：POST /nodes/register 用登记令牌；POST/GET/DELETE /nodes/{id}/grants 使用节点身份令牌；GET /nodes/{id} 和 /capabilities 使用访问令牌。

0.6.0 控制 WS 为 `/v2/nodes/{id}/control`，身份认证后 Hub 分配 connection_generation，所有控制消息 protocol_version=2。capabilities/heartbeat 及其 ack 维护新鲜度；session_open/prepared/stop/closed 管理会话。控制消息限制 64 KiB，上传与截图结果不能放入控制消息。

实际工具参数、对象目录和动作结果走[项目执行协议](工具调用协议.md)的独立连接。旧 v1 控制连接退役，不能把管理路径版本与执行信封版本混同。
