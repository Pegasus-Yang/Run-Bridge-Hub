# Hub 本地开发与联调

本页面向开发者；正常用户不需要在同一设备同时启动两端。Python/uv 环境要求同部署手册，基础工具安装参考官网。

在独立源码目录中：

```bash
uv sync --extra mcp -i http://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
.venv/bin/python -m pytest tests -q
uv build --wheel --out-dir dist -i http://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
```

Hub 包和 [mcp] 不安装 Playwright。真实浏览器测试显式设置 RUNBRIDGE_RUN_BROWSER_TESTS=1；RUNBRIDGE_NODE_ENV 必须指向单独准备的 Node 目录，其中 `.venv/bin/runbridge-node` 为待测版本。浏览器准备遵循 Node 的官方环境要求，PLAYWRIGHT_BROWSERS_PATH 可指向已准备的只读安装缓存。

```bash
RUNBRIDGE_RUN_BROWSER_TESTS=1 RUNBRIDGE_NODE_ENV=/absolute/isolated-node .venv/bin/python -m pytest tests/test_mcp_live.py -q
```

测试动态创建自己的 token、数据库、身份、端口与临时 Profile，结束时只停止本次进程。不要连接原有测试数据库或复制原身份。release 验收先构建 wheel，分别用独立目录和全新 `.venv` 安装 Hub、远程 Node、调用方；Hub 与调用方均验证未安装 Playwright。核对最终业务记录、图像和清理，HTTP 成功不能替代它们。

增加工具时同步维护两端 tool_contract 和契约样例；参数/结果必须有模型，适配器显式分派，不从网络加载类或执行源码。当前架构见[会话管理](../architecture/Playwright执行与会话管理.md)。
