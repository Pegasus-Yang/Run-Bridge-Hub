# RunBridge Hub 项目概况

[项目首页](../../README.md) · [文档导航](../README.md) · [部署与运行](../deployment/部署与运行.md)

当前 Hub 0.5.1 是独立部署的节点接入与连接网关，面向服务部署者及接口调用方。Node 在浏览器所有者设备主动接入，两者通过公开协议协作，分别打包发布。

## 当前职责

Hub 提供登记准入、节点与能力查询、访问许可验证、会话租期与路由、官方浏览器协议转发、PNG 数据流和可选 MCP 工具。SQLite 保留节点、许可、会话和 MCP 请求元数据；活动连接由单进程管理。

Node 身份、浏览器授权及本地运行时由设备所有者按 Node 项目文档维护，Hub 不读取其本机浏览器配置。业务动作和结果断言由调用方负责。

## 阅读路线

部署者按本项目部署指南上线并交付登记资料；接口使用者按[调用方指南](../user-guide/调用方对接与使用.md)、[MCP 指南](../user-guide/MCP浏览器接入.md)或[画面指南](../user-guide/浏览器画面流接入.md)接入。

源码构建、同机两端调试和回归见[开发与联调](../development/本地开发与联调.md)。设计与历史验收保留原决策／日期，不作为当前部署步骤。

独立业务 HTTP 执行、Appium／ADB、单标签页授权和容量目标仍是后续范围，不能从设计材料推断已实现。
