# Tool invocation protocol

[简体中文](工具调用协议.md) · English

Execution protocol **2**, `playwright` tool API **1**, paired with Hub 0.9.2 / Node 0.8.1. Enrollment, pool, lease, and capability HTTP paths retain `/v1`; path versions and execution envelope versions are independent.

## HTTP endpoints

Protected execution/session queries use the lease access token in Authorization. Enrollment uses its enrollment credential; pool queries and claims use the Hub credential. Device connections use Node identity. See [lease API](Node使用权租约接口.en.md).

| Endpoint | Behavior |
| --- | --- |
| `GET /v1/nodes/{node_id}/capabilities` | Authorized actual capabilities and freshness |
| `GET /v2/nodes/{node_id}/tools` | Available methods, input/output schemas, defaults, resources |
| `POST /v2/nodes/{node_id}/sessions` | Create, returning 201; required `resource_id`, tool default `playwright`, optional but recommended retained `request_id`, session lease default 300 seconds, range 1–3600 |
| `GET /v2/sessions/{session_id}` | Same-lease session, object directory, and visual view |
| `DELETE /v2/sessions/{session_id}` | Idempotent close, waiting at most 10 seconds; inspect cleanup |
| `POST /v2/sessions/{session_id}/commands` | Submit a method; 200 terminal or 202 in progress |
| `GET /v2/sessions/{session_id}/commands/{request_id}` | Query without repeating the action |

Retired `/v1` session and `/playwright` / `/cdp` entries return 410 `NATIVE_API_RETIRED`. There is no native official SDK connection address.

## Envelope, targets, and locators

Client commands require `request_id`, `method`, and `target`; `params` defaults to `{}`. IDs contain 1–128 characters, starting with an ASCII letter/digit, followed by letters, digits, hyphens, or underscores.

```json
{"request_id":"goto_1","method":"page.goto","target":{"type":"page","id":"page_from_session"},"params":{"url":"https://example.com","timeout":10000}}
```

Node creates session-bound Browser/Context/Page references. A session target's ID is the session ID. Locators are step lists under a Page, not reusable remote locator objects. At most 16 steps are accepted:

| Step | Parameters |
| --- | --- |
| `frame_locator` / `locator` | String `selector` |
| `get_by_role` | `role`, optional `name` / `exact` |
| `get_by_label` / `get_by_text` | `text`, optional `exact` |
| `get_by_test_id` | `test_id` |

The final step cannot be only `frame_locator`. Element actions require a nonempty locator with a unique match; no implicit first-match selection occurs. Resolution and SDK calls happen on Node.

Hub adds `protocol_version=2`, `type=execute`, `session_id`, `connection_generation`, `tool`, `tool_api_version`, and `remaining_ms`. The 1–30000 ms remaining budget includes queue time. Backend operations use SDK timeouts; an external network timeout does not directly cancel an executing library coroutine. Each session executes sequentially, with at most one running and 16 queued commands. Heartbeats, stop, and frames are handled independently.

## Results

```json
{"protocol_version":2,"type":"result","session_id":"session_example","connection_generation":1,"request_id":"goto_1","status":"SUCCEEDED","execution_outcome":"COMPLETED","result":{"kind":"json","value":{"url":"https://example.com/","title":"Example Domain","http_status":200}},"error":null}
```

For `kind=json`, `value` follows the [method reference](Playwright方法表.en.md). Binary results include `mime_type=image/png`, `encoding=base64`, decoded byte `size`, and `data`. Screenshot limit: 2 MiB; DOM capture: 256 KiB; upload: up to 32 files and 4 MiB decoded total. Params/results do not accept arbitrary Node-local paths.

| Status / outcome | Meaning |
| --- | --- |
| ACCEPTED / DISPATCHED / RUNNING | In progress; query rather than resubmit |
| SUCCEEDED / COMPLETED | Technical completion; verify business outcome separately |
| FAILED / NOT_STARTED | Rejected or queue budget exhausted before entering the action |
| FAILED / OUTCOME_UNKNOWN | Write action entered the backend but failed/timed out; effects may have occurred |
| UNKNOWN / OUTCOME_UNKNOWN | Disconnect, restart, or close prevented a confirmed final outcome |

Errors include `code`, `message`, `stage`, and `retryable=false`. Common codes: METHOD_UNSUPPORTED, INVALID_PARAMS, OBJECT_TYPE_MISMATCH, OBJECT_NOT_FOUND, OBJECT_CLOSED, AMBIGUOUS_TARGET, ACTION_TIMEOUT, RESOURCE_BUSY, REQUEST_ID_CONFLICT, RESULT_UNKNOWN, RESULT_EXPIRED. Authorization/static validation uses HTTP 4xx before acceptance; accepted actions report execution state in the result body.

Identical IDs and normalized content deduplicate; omitted and explicitly supplied defaults are equivalent. Up to 10000 command metadata records per session are retained, terminal records for 24 hours. Full in-memory results are bounded to 128 per session and 64 MiB across Hub. After eviction, status remains with `result_available=false`. Unconfirmed actions after restart become UNKNOWN and are not replayed.

## Objects and events

`objects` includes `root`, `contexts`, `pages`, `default_page_id`, `ownership`, `last_dialog`. Page entries contain type/id/page_id/context_id/url; multiple borrowed pages have no guessed default. Node sends increasing `event_seq` snapshots; Hub accepts only the current session, generation, and newer sequence. Queries expose the latest mirror, not a persistent event subscription API. Frames use a [separate visual channel](浏览器画面流接口.en.md).

Node sends `session_ready` with runtime version and objects over execution, receives `session_ready_ack`, then sends `session_prepared` over control, avoiding large object directories in the 64 KiB control channel. Worker IPC uses a four-byte big-endian length followed by UTF-8 JSON, maximum 16 MiB, without a local Playwright server port.

Node initiates `WS /v2/nodes/{node_id}/sessions/{session_id}/execution` with Node identity Bearer and `x-runbridge-generation`. Messages match protocol 2, session ID, and generation. `command_ack` / `command_started` acknowledge/start execution, `result` terminates it, and object events carry increasing sequence numbers. A failed connection interrupts the session without recreating objects or replaying actions. The detailed [control contract is in Chinese](R1接口与控制协议.md).

New tools require declarations and local adapters on both sides. Generic authorization, queues, request state, and result envelopes remain. Unregistered methods/tools are not invoked through reflection, eval, or exec.
