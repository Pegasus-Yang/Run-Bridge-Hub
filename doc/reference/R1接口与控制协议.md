# RunBridge R1 接口与控制协议

> 本文件说明 0.4.0 沿用的 v1 基础控制合同。会话与原生执行见[会话参考](会话接口与原生连接.md)，独立画面见[画面参考](浏览器画面流接口.md)。

[文档导航](../README.md) · [当前实现](../architecture/R0与R1实现.md)

以下接口覆盖登记、许可、节点查询和心跳。当前已实现的资源会话、Playwright/CDP 和画面入口一并列于[对外接口总览](对外接口总览.md)。

## 认证角色

原有接口统一使用 `Authorization: Bearer ...`，凭据原值只放在头或私有配置文件，不放在 URL、普通查询响应或日志中。0.4.0 的画面订阅另支持浏览器首条 auth 消息，详见[画面流合同](浏览器画面流接口.md)；控制接口仍使用原认证方式。

| 凭据 | 用途 |
| --- | --- |
| 首次登记凭据 | 部署方允许 Node 首次登记或使用同一身份幂等重试 |
| 节点身份凭据 | 指定节点的控制连接、许可签发/列表/撤销 |
| 对接码 | 指定节点/资源的节点与能力查询；受期限和撤销约束 |

## HTTP 接口

| 方法与路径 | 认证 | 行为 |
| --- | --- | --- |
| `GET /health` | 无 | 已完成应用初始化后的健康状态 |
| `POST /v1/nodes/register` | 登记凭据 | 请求 `node_id`、`name`、`node_token`；新登记 201，同身份重试 200 |
| `POST /v1/nodes/{node_id}/grants` | 节点身份 | 请求可选 `resource_ids`、`expires_in_seconds`；201，凭据只在创建响应交付 |
| `GET /v1/nodes/{node_id}/grants` | 节点身份 | 返回许可 ID、范围、创建/到期/撤销时间，不含原值或摘要 |
| `DELETE /v1/nodes/{node_id}/grants/{grant_id}` | 节点身份 | 撤销许可；204；不存在 404；重复撤销保持撤销状态 |
| `GET /v1/nodes/{node_id}` | 对接码 | 节点连接与能力视图 |
| `GET /v1/nodes/{node_id}/capabilities` | 对接码 | 同一视图，保留判断能力新鲜度所需的连接信息 |

`resource_ids = null` 表示该节点全部可见资源；列表表示仅对应资源。签发许可不代表资源已就绪或已占用；基础查询按范围过滤，执行会话申请还会检查资源范围、真实就绪和独占预约。调用方凭据不能管理许可或接入 Node 控制连接。

节点视图包含：`protocol_version`、`node_id`、`name`、`connection_status`、`connection_generation`、`heartbeat_count`、`last_seen_at`、`capabilities_observed_at`、`observation_age_ms`、`capabilities_stale` 和 `capabilities`。能力内含 `host`、`backends`、`resources`；工具扩展与资源状态采用明确字段，不据安装信息生成虚假的 READY 设备。

主要 HTTP 错误：401 无效/到期/撤销凭据；403 合法对接码的节点范围不符；409 已登记 ID 与其他身份冲突；422 控制参数错误。错误响应只含公开码与字段位置/错误类型，不回显请求输入。

## WebSocket 控制接口

`/v1/nodes/{node_id}/control` 使用节点身份头认证。认证失败在接受连接之前拒绝，实际 Uvicorn 返回握手 HTTP 403。

| 方向 | type | 内容 |
| --- | --- | --- |
| Hub → Node | `welcome` | 节点 ID、连接代次、心跳间隔与超时 |
| Node → Hub | `capabilities` | 当前代次、能力快照；必须先于心跳 |
| Hub → Node | `capabilities_ack` | 当前代次、服务器观察时间、心跳计数 |
| Node → Hub | `heartbeat` | 当前代次 |
| Hub → Node | `heartbeat_ack` | 当前代次、服务器观察时间、心跳计数 |
| Hub → Node | `error` | 公开错误码；随后关闭无效控制连接 |

所有消息含 `protocol_version = 1`。控制模型拒绝额外字段和不支持的版本，帧为文本 JSON，最大 65,536 字节。代次由 Hub 分配，迟到或伪造代次拒绝，不更新当前节点观察。

关闭语义：1008 控制错误/许可拒绝；4001 同节点新连接替换；1001 心跳超时或服务关闭；1012 显式服务重启。普通网络失联可重试，身份和合同拒绝不无限重试。

## 公开字段与私有文件

Node CLI 的登记结果和 inspect JSON 不含秘密。`grant` 将创建响应中的对接码保存到单独的私有访问文件，只打印许可 ID 和文件路径；访问文件不包含节点身份秘密。

本服务的 Python 模型和原生后端协议保持分离。上述心跳/能力合同不构成执行工具 API 的替代层。实现依据：[FastAPI WebSocket](https://fastapi.tiangolo.com/advanced/websockets/)、[websockets asyncio client](https://websockets.readthedocs.io/en/stable/reference/asyncio/client.html)。

## 0.4.0 查询扩展

节点及能力查询默认增加 visual.supported 与 visual.streams，只返回当前许可的活动画面流。会话查询增加单个 visual。画面字段不进入此控制消息合同，旧的严格查询解析器须同步升级；具体字段见[画面流接口](浏览器画面流接口.md)。
