# Hub 配置与凭据

[文档导航](../README.md) · [部署与运行](../deployment/部署与运行.md) · [Hub 接入检查](../user-guide/快速开始.md)

本文对应 Hub **0.5.1**，仅说明服务端部署文件、Hub CLI 和接口调用方收到的访问许可。Node 设备的身份、浏览器 JSON 及操作步骤由 Node 项目维护。示例中的 EXAMPLE_ONLY、ID 和时间均为演示值。

## 1. Hub 文件与格式规则

| 文件 | 格式／准备者 | 读取入口 |
| --- | --- | --- |
| `enrollment.token` | Hub 生成的 UTF-8 一行纯文本 | `serve --enrollment-token-file` |
| `hub.sqlite3` | Hub 自动创建／迁移的 SQLite 数据库 | `serve --db-path` |
| `deploy-constraints.txt`，可选 | 发布者导出的 requirements 约束文本 | `uv pip install --constraint` |

Hub CLI 使用启动参数，未提供通用 JSON 配置文件入口。辅助开发脚本自己的 JSON 不属于产品配置。数据库可能伴随 WAL／SHM 文件，备份使用部署指南的一致性方法。所有相对路径以 Hub 服务的工作目录为准。程序不会自动加载 `.env`。

## 2. 登记文件

文件只有令牌正文一行，不加引号、JSON、Bearer 前缀或 token=。生成器写入 64 字符随机令牌和换行，示例：

```text
EXAMPLE_ONLY_ENROLLMENT_TOKEN_DO_NOT_USE_00000000000000000000000
```

在 Hub 部署目录首次生成：

```bash
.venv/bin/runbridge-hub generate-token --output .runbridge/enrollment.token
```

`--output` 必填，是文件路径；新建父目录和文件使用私有权限，文件存在时拒绝覆盖。命令只输出保存位置。将生成的同一份文件安全交给 Node 所有者，不在另一台机器另生成不同值。

`serve` 优先读取 `--enrollment-token-file`，省略时才读取 `RUNBRIDGE_ENROLLMENT_TOKEN`。文件按 UTF-8 读取并去掉首尾空白；显式文件不存在或为空时不回退环境变量。Hub 接受 32–256 字符的登记令牌。更换登记令牌后重启 Hub 才生效，已有节点身份和调用许可保持独立。

## 3. Hub 启动参数

基础启动命令在 **Hub 部署目录**运行：

```bash
.venv/bin/runbridge-hub serve --host 0.0.0.0 --port 8787 --db-path .runbridge/hub.sqlite3 --enrollment-token-file .runbridge/enrollment.token
```

| 参数 | 默认值／类型 | 含义 |
| --- | --- | --- |
| `--host` | `127.0.0.1`，字符串 | Hub 监听地址。远程 Node 使用可达网卡地址；监听 `0.0.0.0` 时客户端仍填写实际 IP／域名 |
| `--port` | `8787`，整数 | HTTP、原生 WebSocket、画面与可选 MCP 共用的监听端口 |
| `--db-path` | `.runbridge/hub.sqlite3`，路径 | SQLite 文件；父目录自动创建，部署用户必须可写；重启继续使用同一文件 |
| `--enrollment-token-file` | 未设置，路径 | 第 2 节的纯文本登记文件；不提供时须设置 `RUNBRIDGE_ENROLLMENT_TOKEN` |
| `--heartbeat-interval` | `30`，秒，可带小数 | 必须大于 0；Hub 告知 Node 的心跳发送间隔 |
| `--heartbeat-timeout` | `90`，秒，可带小数 | 必须大于心跳间隔；超时后判断控制连接失联 |
| `--enable-mcp` | 关闭，开关 | 开启 `/mcp`；须先安装 Hub 的 `mcp` extra，Node 无需 MCP 包 |
| `--mcp-native-url` | 按监听地址／端口生成 | Hub 进程通过 SDK 连接自身原生接口的 HTTP(S) 根地址；不是 Node 地址，也不带 `/mcp` |
| `--mcp-allowed-host` | 在内置允许列表上追加，可重复 | MCP 请求允许的 Host，不带协议或路径，例如 `hub.example.com`、`hub.example.com:8787` 或 `hub.example.com:*` |
| `--mcp-allowed-origin` | 空列表，可重复 | 允许的网页 Origin，例如 `https://agent.example.com`；不带页面路径。无 Origin 的服务端客户端不需要设置 |

MCP 内部地址默认将监听 `0.0.0.0` 转为 `127.0.0.1`，将 `::` 转为 `[::1]`，再组合 `http://地址:端口`。自定义值必须指向当前 Hub、内部可达，且不含用户名密码、查询、片段或路径前缀。

内置 MCP Host 允许列表为 `127.0.0.1`、`127.0.0.1:*`、`localhost`、`localhost:*`、`[::1]`、`[::1]:*`；额外 Host 是追加而非替换。Host／Origin 均不能用单独的 `*` 放行全部来源；允许项可用 `:*` 匹配端口。Host 指请求到达 Hub 时的头部值，Origin 指网页来源，两者含义不同，也不替代访问令牌。

例如已安装 Hub `mcp` extra，外部通过 `https://hub.example.com/mcp` 访问，而 Hub 本地监听 8787：

```bash
.venv/bin/runbridge-hub serve --host 0.0.0.0 --port 8787 --db-path .runbridge/hub.sqlite3 --enrollment-token-file .runbridge/enrollment.token --enable-mcp --mcp-native-url http://127.0.0.1:8787 --mcp-allowed-host hub.example.com
```

Hub 固定一个 ASGI Worker。TLS 终止和反向代理由部署设施提供，CLI 没有证书或 Worker 数配置参数；网络要求见[部署与运行](../deployment/部署与运行.md)。

## 4. 调用方访问文件

由远程 Node 所有者签发并交付给接口调用方，文件名也可以是 `chrome-access.json`、`playwright-access.json` 或 `agent-access.json`，内容格式相同：

```json
{
  "hub_url": "http://192.168.50.10:8787",
  "node_id": "node_11111111111111111111111111111111",
  "grant_id": "grant_22222222222222222222222222222222",
  "access_token": "EXAMPLE_ONLY_ACCESS_TOKEN_DO_NOT_USE_00000000000000000000000000000",
  "expires_at": "2030-01-01T01:00:00Z"
}
```

| 字段 | 必填／格式 | 含义 |
| --- | --- | --- |
| `hub_url` | 必填，HTTP(S) 基址 | 调用方连接的 Hub，须从调用方网络可达；不能填写 Node 的浏览器调试地址 |
| `node_id` | 必填，标识符 | 许可所属节点，不得替换为另一节点 |
| `grant_id` | 必填，标识符 | 所有者撤销许可时使用的 ID |
| `access_token` | 必填，字符串 | Hub 签发的调用凭据原值；JSON 中不加 `Bearer `，请求时使用 `Authorization: Bearer <access_token>` |
| `expires_at` | 可省略或 `null`；否则为带时区的 ISO 8601 时间 | Hub 返回的到期时间，如 `Z` 或 `+08:00`；`null` 表示签发时未设置期限，不是永久不可撤销 |

时间和令牌均由签发命令填入，示例时间不是实际期限。资源范围由所有者在签发时写入 Hub 的许可记录，文件中没有 `resource_ids` 字段；不要自行添加。更改本地 `expires_at`、ID 或令牌不能修改 Hub 授权，续期须重新签发。

MCP 客户端读取同一访问令牌，以每次请求头认证，MCP 地址为 Hub 基址加 `/mcp`。`node_token` 和 `enrollment.token` 都不能替代它。调用方只接收访问文件，Node 身份、登记文件及本机浏览器配置由所有者保留。

## 5. 权限与环境变量

登记文件由生成命令以 POSIX 0600 写入，新建父目录使用 0700；既有目录不会自动收紧权限。复制的文件也设置 0600，不放入静态目录或 Git。

| 变量 | 含义 |
| --- | --- |
| `RUNBRIDGE_ENROLLMENT_TOKEN` | `serve` 未提供登记文件时读取令牌正文，长度 32–256，不含 Bearer 前缀 |
| `PATH` | 服务进程查找全局 uv 等工具；长期服务固定工作目录和 CLI 路径 |
| `UV_CACHE_DIR` | uv 的可选安装缓存；不决定 Hub 使用哪一套虚拟环境 |

常见问题按[Hub 运行与排障](../deployment/运行与排障.md)检查。接口使用者应提交访问许可，不能用登记令牌代替。
