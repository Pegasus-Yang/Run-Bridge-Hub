# Hub 调用方对接与使用

[文档导航](../README.md) · [接口总览](../reference/对外接口总览.md) · [调用方示例](../reference/examples/README.md)

本指南面向使用 Hub 0.5.1 公开接口的脚本、平台和服务。调用方在自己的目录准备客户端环境，连接已部署的远程 Hub；浏览器运行在所有者设备，调用方不启动 Hub 或 Node。

## 1. 取得访问许可

从 Node 所有者取得访问 JSON 和实际资源 ID。文件包含 `hub_url/node_id/grant_id/access_token/expires_at`；内容格式见[访问文件参考](../reference/部署配置与凭据.md)。

许可须覆盖资源并且有效。创建、查询、原生连接、画面和释放使用同一份许可。Node 身份、登记文件和浏览器调试端点不交付给调用方。

## 2. 准备独立调用目录

以下都在调用方自己的工作目录执行：

```bash
uv venv --python 3.14 .venv
uv pip install --python .venv/bin/python 'playwright==1.63.0' 'httpx>=0.28,<1' 'websockets>=15,<18' -i http://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
mkdir -p examples artifacts
```

将本项目文档包中的[执行脚本](../reference/examples/执行会话调用.py)和[画面订阅脚本](../reference/examples/画面流订阅.py)复制到自己的 `examples/`。访问文件另存为私有 `access.json`，不放进公开静态目录。

这两份脚本只用公开接口。调用方不安装 Hub／Node 包，也不执行浏览器安装；只用 HTTP 查询可仅安装 httpx，只订阅画面可仅安装 httpx／websockets。

## 3. 查询节点与资源

将下面代码保存为调用方目录的 `inspect_access.py`：

```python
import json
from pathlib import Path

import httpx

access = json.loads(Path("access.json").read_text(encoding="utf-8"))
response = httpx.get(
    url=f"{access['hub_url'].rstrip('/')}/v1/nodes/{access['node_id']}",
    headers={"Authorization": f"Bearer {access['access_token']}"},
    timeout=15,
)
response.raise_for_status()
print(json.dumps(response.json(), ensure_ascii=False, indent=2))
```

执行：

```bash
.venv/bin/python inspect_access.py
```

核对 ONLINE、capabilities_stale=false、所需资源 READY/FREE。资源 ID 从返回值及所有者交付信息取得，不从浏览器名称猜测。

## 4. 使用官方 SDK 执行与释放

创建请求使用实际 SDK 版本，例如：

```json
{"resource_id":"chromium","client_version":"1.63.0","lease_seconds":300}
```

Hub 等待 Node 准备后返回 READY；HTTP 创建超时使用大于 30 秒的值，示例为 40 秒。调用方通过返回的 `native_protocol/native_path` 选择官方连接方式。

| 协议 | SDK 入口 | 结束含义 |
| --- | --- | --- |
| playwright | `chromium.connect()` | 使用本次独立浏览器，结束后回收自建实例 |
| cdp | `chromium.connect_over_cdp(no_defaults=True)` | 使用授权实例的已有 contexts/pages，结束后释放借用连接 |

将 Hub 基址转换为 WS／WSS 并拼接返回路径，保留代理前缀；令牌放入 Authorization 头。一个会话接入一个原生 SDK 连接，连接成功后进入 ACTIVE。

受管理 Chromium 示例，默认页面不依赖外网：

```bash
.venv/bin/python examples/执行会话调用.py --access-file access.json --resource-id chromium --screenshot artifacts/managed.png
```

已有 Chrome，读取授权实例内唯一匹配的已有页面：

```bash
.venv/bin/python examples/执行会话调用.py --access-file access.json --resource-id chrome --page-url 'https://your-test-system.example/account' --screenshot artifacts/chrome.png
```

替换实际资源 ID 和已有页面的精确 URL。Chrome 示例不导航原页面，有零个或多个匹配时失败并释放。URL 只用于示例选页，不构成服务端单页授权。受管理示例访问业务系统时可增加 `--url`，目标须从浏览器设备网络可达。

截图保存在调用方。输出 ACTIVE、标题和 PNG 证明连接及读取成功；业务验证须加入真实断言。

## 5. 加入业务动作

在脚本标记的位置使用官方 Page／Locator，例如已授权测试页上的表单：

```python
from playwright.async_api import expect

await page.get_by_role(role="textbox", name="内容").fill(value="测试内容")
await page.get_by_role(role="button", name="提交").click()
await expect(page.locator(selector="#result")).to_have_text(expected="测试内容")
```

目标与断言按真实应用修改。已有 Chrome 的页面动作会影响原实例；断开连接不回滚已发生的业务结果。

无论动作是否成功，都在 finally 里断开 SDK 并请求 DELETE 释放，检查 cleanup。COMPLETE 说明相应资源清理已确认，不代表业务通过。

## 6. 查询或释放已有会话

使用创建该会话的同一访问文件，替换真实 session_id 后可直接调用 Hub：

```python
import json
from pathlib import Path

import httpx

access = json.loads(Path("access.json").read_text(encoding="utf-8"))
session_id = "session_example"
url = f"{access['hub_url'].rstrip('/')}/v1/sessions/{session_id}"
headers = {"Authorization": f"Bearer {access['access_token']}"}
response = httpx.get(url=url, headers=headers, timeout=15)
response.raise_for_status()
print(response.json())
# 需要释放时调用 httpx.delete(url=url, headers=headers, timeout=15)，并检查响应。
```

接口合同见[会话参考](../reference/会话接口与原生连接.md)。示例会自行创建新会话，不与手工创建的 READY 会话混用。

## 7. 同时查看画面

需要让另一个消费者查看时，执行示例增加 `--hold-seconds 60`，保存输出的 session_id，再按[画面订阅](浏览器画面流接入.md)操作。保持时长不延长租期或许可期限；原生连接结束后画面也停止。

网络错误可能发生在业务动作已经生效之后，先观察实际状态再决定后续动作，不自动重放提交。故障码和 Hub 运维见[运行与排障](../deployment/运行与排障.md)。
