# Hub deployment and operation

[简体中文](部署与运行.md) · English

Applies to **Hub 0.9.2 / Node 0.8.1**. Run commands on the **Hub server**. Source installation starts in the [README](../../README.en.md#quick-start); this guide installs a wheel into a separate directory. Use that directory's `.venv` consistently. Clients follow the [client guide](../user-guide/调用方对接与使用.en.md).

## 1. Requirements and handoff material

Prepare Python **3.14.x**, global [uv](https://docs.astral.sh/uv/getting-started/installation/), a shell, a reachable HTTP(S) base URL and port, and `runbridge_hub-0.9.2-py3-none-any.whl` with its manuals. See [Python](https://www.python.org/downloads/) for the runtime. Hub needs no browser, Playwright, or Node.js. The examples place the wheel in `~/Downloads/`.

## 2. Create a deployment environment

```bash
mkdir -p ~/runbridge-hub
cd ~/runbridge-hub
uv venv --python 3.14 .venv
uv pip install --python .venv/bin/python "$HOME/Downloads/runbridge_hub-0.9.2-py3-none-any.whl[mcp]" -i http://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
umask 077
mkdir -p .runbridge
chmod 700 .runbridge
```

The optional `[mcp]` extra can be omitted for HTTP-only use. `.venv` contains this installation; `.runbridge` holds private data. Shell commands target macOS / Linux. Windows uses corresponding commands under `.venv/Scripts/`.

## 3. Generate separate credentials

```bash
.venv/bin/runbridge-hub generate-token --output .runbridge/enrollment.token
.venv/bin/runbridge-hub generate-token --output .runbridge/hub.token
```

Files are created exclusively with private directory permissions and file mode `600`. Reuse them on restarts. Give **enrollment.token** to Node maintainers and **hub.token** to authorized clients. Token text is UTF-8, single-line, normally 64 characters; the accepted length is 32–256. A final newline is allowed. Do not add JSON, quotes, `Bearer `, or `token=`. An illustration, never a real credential:

```text
EXAMPLE_ONLY_ENROLLMENT_TOKEN_DO_NOT_USE_00000000000000000000000
```

## 4. Configure, start, and verify

Create `hub.yaml`:

```yaml
host: 0.0.0.0
enrollment_token_file: .runbridge/enrollment.token
hub_token_file: .runbridge/hub.token
public_url: http://hub.example:8787  # Replace with the actual base URL.
```

Omit `host` for local-only binding. Defaults are port `8787` and database `.runbridge/hub.sqlite3`. Relative paths resolve from the YAML directory, without expanding `~`, `$HOME`, or shell expressions. See [parameters](../reference/参数详解.en.md) and [annotated YAML](../reference/examples/Hub启动配置.en.yaml).

```bash
.venv/bin/runbridge-hub serve --settings hub.yaml
```

Keep the foreground process running. `--settings` cannot be combined with other startup options. From a second terminal:

```bash
curl --fail http://127.0.0.1:8787/health
.venv/bin/python -c 'from importlib.metadata import version; print(version("runbridge-hub"))'
```

Expect `{"status":"ok","protocol_version":2}` and version `0.9.2`. Repeat the health check using the actual base URL from the Node network. `0.0.0.0` is not a client URL. Health does not check browsers.

With `[mcp]` installed, set `mcp_enabled: true` and restart to expose `/mcp`. By default, all Host values are allowed. Restrict them only when needed:

```yaml
mcp_allowed_hosts:
  - "hub.example:8787"
```

An omitted list or `[]` has no Host restriction. A nonempty list permits only listed URL hosts and ports, including any required loopback addresses; entries have no scheme or path. This is not a list of caller or Node IPs. Normal clients without Origin do not require an Origin list.

HTTP, MCP, and the dashboard share the listener. Deploy one Hub process and one worker. The environment administrator manages HTTPS and reverse proxies, including WebSocket forwarding and long connections.

The dashboard is enabled by default. Startup logs include its separate read-only token and a `Dashboard URL` with `?token=…`. The default token file is `web.token` beside the database. Replace a logged loopback host for remote access. Use `web_token_file` for another file or `web_enabled: false` to disable the page and its API; see the [dashboard guide](../user-guide/节点总览.en.md).

## 5. Hand off the correct material

Privately deliver the actual enrollment file and a completed note, for example:

```text
Hub: 0.9.2; paired Node: 0.8.1
Hub base URL: http://192.168.50.10:8787
Enrollment attachment: enrollment.token, identical to the file read by Hub
Node wheel: runbridge_node-0.8.1-py3-none-any.whl
Node documentation: deployment guide and annotated YAML
MCP: disabled, or enabled at the actual base URL plus /mcp
```

Base URLs do not end in `/health`, `/v1`, `/v2`, or `/mcp`. Confirm reachability from both Node and client networks. Node enrolls and reports capabilities; it does not issue client access files. Separately provide clients with `hub.token` and the actual `public_url`. Clients claim Node and save that claim's `access_config`; Hub has no user-account system.

Enrollment, device identity, client lease, and dashboard credentials have separate roles. See [configuration and credentials](../reference/部署配置与凭据.en.md).

## 6. Long-term operation, shutdown, and backups

Configure the environment's process manager with the deployment directory, absolute CLI and YAML paths, and log destination. Use the same user and `.venv`; RunBridge does not install a service manager. CLI relative paths use the process working directory.

Before stopping, have clients finish and release resources. Use Ctrl+C or SIGTERM. Stop Hub before backing up `hub.yaml` and `.runbridge/`, including SQLite side files. SQLite stores identity hashes, leases, sessions, and request metadata; full action parameters, uploads, and screenshots are not stored there. Full results are cached in memory.

Restart interrupts old sessions; it does not restore browser objects or replay commands. Clients inspect old requests before explicitly starting a new session. See [operations and upgrades](运行与排障.en.md). Detailed source builds and same-machine integration remain in the [development manual (Chinese)](../development/本地开发与联调.md).
