Hub 测试有一条 Starlette TestClient 使用 HTTPX 的弃用提示；当前兼容路径和真实进程验收均通过，运行锁定为已验证版本，未把提示隐藏。

测试代码位于各项目 `tests/`。Node 联调运行各项目自己的 `.venv/` 入口，不通过跨项目导入模拟服务器；所有凭据和数据库为本轮临时测试数据。服务停止后测试资源已清理。

能力资源过滤的 Hub 测试使用显式模拟快照；默认实际 Node 的资源目录为空。没有浏览器/手机操作、节点侧业务 HTTP 执行或原生协议转发结果，不能把控制连通当作这些能力已实现。

100 用户、10 并发仍是首期规划目标；容量压测属于 R6。本次没有远程 TLS、跨操作系统、设备驱动或完整原生 API 覆盖的验收结论。
