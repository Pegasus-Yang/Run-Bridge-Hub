# 工具调用协议

当前执行协议为 **2**，工具 `playwright` API **1**，配套 Hub 0.9.0 / Node 0.8.0。登记、许可和能力 HTTP 沿用 `/v1`；这与执行信封版本独立。

## HTTP 接口

所有受保护接口均在 Authorization 中使用访问令牌；登记及许可管理使用对应登记／身份凭据。

| 接口 | 行为 |
| --- | --- |
| GET /v1/nodes/{node_id}/capabilities | 许可范围内的实际能力与新鲜度 |
| GET /v2/nodes/{node_id}/tools | 可用方法、输入/输出 schema、默认值、资源 |
| POST /v2/nodes/{node_id}/sessions | 创建请求，201 返回会话；resource_id 必填、tool 默认 playwright、request_id 可选但建议自行保存、lease_seconds 默认 300（1～3600） |
| GET /v2/sessions/{session_id} | 同一许可的会话、Node 对象目录及 visual 视图 |
| DELETE /v2/sessions/{session_id} | 幂等释放，最多等待 10 秒；检查 cleanup |
| POST /v2/sessions/{session_id}/commands | 提交方法，200 终态／202 进行中 |
| GET /v2/sessions/{session_id}/commands/{request_id} | 不重做动作的状态查询 |

旧 `/v1` 会话及 `/playwright`、`/cdp` 入口返回 410 NATIVE_API_RETIRED。没有官方 SDK 的原生连接地址。

## 信封、目标和 Locator

调用方命令必填 request_id、method、target，params 默认 `{}`。ID 为 1～128 字符，以英文字母或数字开头，后续只含字母、数字、短横线、下划线。

```json
{"request_id":"goto_1","method":"page.goto","target":{"type":"page","id":"page_from_session"},"params":{"url":"https://example.com","timeout":10000}}
```

Browser/Context/Page 引用由 Node 生成并绑定会话；session 类型的 id 就是 session_id。Locator 是 Page 下的步骤列表，不创建可跨请求复用的远程 Locator。步骤最多 16 个，支持：

| method | params |
| --- | --- |
| frame_locator / locator | selector 字符串 |
| get_by_role | role，选填 name/exact |
| get_by_label / get_by_text | text，选填 exact |
| get_by_test_id | test_id |

最后一步不能只是 frame_locator。涉及元素的动作必须传非空 locator，唯一匹配后执行，不会默取第一个。所有定位与库调用发生在 Node。

Hub 下发时补齐 protocol_version=2、type=execute、session_id、connection_generation、tool、tool_api_version、remaining_ms。剩余预算包含 Hub/Node 排队消耗，范围 1～30000 毫秒；SDK 使用库自身超时，外部网络等待不会直接取消正在执行的库协程。动作按会话顺序执行，最多 1 项执行和 16 项等待；心跳、停止、画面独立处理。

## 结果

```json
{"protocol_version":2,"type":"result","session_id":"session_example","connection_generation":1,"request_id":"goto_1","status":"SUCCEEDED","execution_outcome":"COMPLETED","result":{"kind":"json","value":{"url":"https://example.com/","title":"Example Domain","http_status":200}},"error":null}
```

结果 kind=json 时 value 的类型由[方法表](Playwright方法表.md)规定；kind=binary 时含 mime_type=image/png、encoding=base64、size（解码字节数）、data。截图最大 2 MiB，DOM 采集最大 256 KiB，上传最多 32 个文件且解码合计 4 MiB。参数及结果不支持 Node 本地路径。

| 状态／结果 | 含义 |
| --- | --- |
| ACCEPTED / DISPATCHED / RUNNING | 进行中，查询而不重发 |
| SUCCEEDED / COMPLETED | 得到技术完成结果，业务仍需验证 |
| FAILED / NOT_STARTED | 已拒绝或排队预算用尽，未进入动作 |
| FAILED / OUTCOME_UNKNOWN | 写操作已进入库调用但超时／失败，可能发生副作用 |
| UNKNOWN / OUTCOME_UNKNOWN | 失联、重启、关闭等导致最终动作结果未确认 |

错误对象含 code/message/stage/retryable=false。常见 METHOD_UNSUPPORTED、INVALID_PARAMS、OBJECT_TYPE_MISMATCH、OBJECT_NOT_FOUND、OBJECT_CLOSED、AMBIGUOUS_TARGET、ACTION_TIMEOUT、RESOURCE_BUSY、REQUEST_ID_CONFLICT、RESULT_UNKNOWN、RESULT_EXPIRED。鉴权和静态校验在接受前使用相应 4xx；动作接受后使用结果体的 status。

同 ID 同内容按标准化参数摘要去重；默认参数显式填写与省略等价。命令元数据最多每会话 10000 项，终态保留 24 小时；完整结果在内存中每会话最多 128 项、Hub 合计 64 MiB。淘汰后仍返回状态与 result_available=false；重启未确认动作标 UNKNOWN，不重放。

## 对象与事件

`objects` 含 root、contexts、pages、default_page_id、ownership、last_dialog。pages 每项包含 type/id/page_id/context_id/url；多页借用时默认页为 null。Node 按递增 event_seq 发目录快照，Hub 只接受当前会话、连接代次和更新序号；查询返回最新镜像。事件不是持久化订阅 API，实时图片走[独立画面通道](浏览器画面流接口.md)。

Node 在执行通道发送 session_ready（运行版本及对象目录），收到 Hub 确认后才在控制通道报告 session_prepared，避免目录挤入 64 KiB 控制消息。worker 与 Node 本地使用 4 字节大端长度前缀加 UTF-8 JSON，最大 16 MiB，不开启本地 Playwright 服务端口。

执行连接为 `WS /v2/nodes/{node_id}/sessions/{session_id}/execution`，由 Node 主动建立，握手使用 Node 身份 Bearer 和 `x-runbridge-generation`。所有消息必须匹配该会话的 protocol_version=2、session_id、connection_generation。`session_ready` 另含 runtime_version、objects；Hub 以 `session_ready_ack` 确认。动作消息为 `execute`，Node 用 `command_ack` / `command_started` 标记接受与开始，用 `result` 返回终态；目录事件使用递增 event_seq。执行连接异常关闭使会话中断，不自动重建原对象或重发动作。控制消息字段见[管理与控制合同](R1接口与控制协议.md)。

新增工具需要在两端登记版本化方法输入/输出声明、资源和 Node 本地适配器；通用鉴权、排队、请求状态与结果信封不变。未登记的方法或工具不会通过反射、eval 或 exec 执行。
