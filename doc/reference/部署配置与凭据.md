# Hub 配置与凭据

适用于 0.6.0。部署步骤见[安装手册](../deployment/部署与运行.md)。

## 启动参数

| CLI 参数 | 默认值 | 含义 |
| --- | --- | --- |
| --host | 127.0.0.1 | 监听网卡；远程访问时显式设置可达地址或 0.0.0.0 |
| --port | 8787 | TCP 端口 |
| --db-path | .runbridge/hub.sqlite3 | SQLite 数据文件；相对当前工作目录 |
| --enrollment-token-file | 无 | UTF-8 单行登记令牌文件；优先于 RUNBRIDGE_ENROLLMENT_TOKEN |
| --heartbeat-interval | 30 | 秒；节点应用心跳间隔 |
| --heartbeat-timeout | 90 | 秒；必须大于发送间隔，过期视为失联 |
| --enable-mcp | false | 启用 /mcp；需安装 [mcp] extra |
| --mcp-allowed-host | 仅本机 Host | 可重复追加实际 MCP Host，含端口；支持 host:*，不接受单独 * |
| --mcp-allowed-origin | 空列表 | 可重复指定浏览器 Origin；无 Origin 的普通客户端不需要填写 |

`--mcp-native-url` 已删除。Hub 不自连接浏览器服务。单进程单 worker；HTTP 与 WS 执行消息最大 16 MiB，控制消息 64 KiB，MCP 请求体 8 MiB。

## 文件的产生、格式与持有人

| 文件 | 谁生成 | 格式／字段来源 | 谁保存 |
| --- | --- | --- | --- |
| enrollment.token | Hub 的 generate-token | 随机单行文本，32～256 字符，不带引号或 Bearer | Hub 部署者，私密交付 Node 所有者 |
| hub.sqlite3 | Hub 启动自动创建／升级 | SQLite schema 4，身份与许可只保存令牌哈希 | Hub 部署者 |
| node.json | Node 首次启动生成 | config_version=1、hub_url、node_id、name、node_token | Node 所有者；不交给调用方 |
| access.json | Node 所有者请求许可，Hub 签发 | hub_url/node_id 来自身份；grant_id/access_token/expires_at 来自 Hub | 调用方及 Node 所有者 |

访问 JSON 只含 hub_url、node_id、grant_id、access_token、expires_at；到期时间为带时区 ISO 8601 或 null。资源 ID 另附在交接说明。登记文本不能用于调用，身份令牌不能替代访问许可。

私有文本/JSON 使用 UTF-8，目录 700、文件 600。Hub generate-token 拒绝覆盖；Node 身份和访问文件的格式由 Node 手册维护。数据库备份前正常停止单实例，勿直接复制正在写入的 SQLite 文件代替一致性备份。
