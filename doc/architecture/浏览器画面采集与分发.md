# 浏览器画面采集与分发

Hub 0.8.0 配合 Node 0.7.0 时，managed 画面由 Node 的 Python worker 采集其同一个实际 Page；公开 target_id 与动作的 page_id 一致。managed 切换标签页同时选择采集目标；borrowed 通过公开画面选择接口明确选页。managed 使用同一 Page.screenshot 的 1500 毫秒库内超时，弹窗或导航期间失败后继续采集。采集与动作任务独立，Node 保留最新帧，网络慢时丢弃旧待发帧，不无限累积。

borrowed 画面继续使用可选 Browscreen 0.3.1～0.3.x 的隔离进程；Node 将浏览器内部 target 映射为本会话的项目 Page 引用，内部 CDP target 不交付给调用方。普通 borrowed 动作不依赖这个扩展。

上传与订阅使用现有 runbridge-visual-v1 格式。握手明确声明 capture_backend=python-playwright 或 browscreen，并分别报告真实运行库版本。Python 采集不会伪装成 Browscreen。会话未 ACTIVE 时等待，关闭、撤销、失联或画面超过新鲜度窗口后撤下旧图。

画面只供观察，不是控制界面、视频编码、可靠录屏或桌面远控。截图成功不替代业务数据验证。高级 Chrome 窗口遮挡/最小化/锁屏表现取决于外部浏览器和系统，本项目不承诺这些场景始终出图。
