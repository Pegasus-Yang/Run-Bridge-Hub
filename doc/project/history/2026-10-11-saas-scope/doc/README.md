# 文档导航

[返回研究首页](../README.md)

本目录保存 2026-10-11 对 SaaS AI 测试平台与客户执行节点的研究。所有架构和协议均为评审提案，尚未实施。

最新讨论建议把节点注册、网关和客户端作为独立服务。[独立节点服务与对外契约](design/独立节点服务与对外契约.md)是这一拆分的主要阅读入口；早期平台统一注册的架构与消息例子保留为历史方案，不再作为独立节点接入的必选合同。
