# Node 使用权租约改造验收

日期：2026-10-23。版本：Hub 0.9.1 / Node 0.8.1。本次是本地源码、隔离服务与发行包验收；没有升级日常或远程部署，没有推送。

## 已交付行为

Hub不维护用户、账号或ACL。共享hub_token仅用于只读资源池和领取整个Node；本次access_token用于执行、续租和释放。每个Node最多一份HELD/RELEASING/QUARANTINED租约，数据库唯一索引与会话分配共用节点锁。

默认租期3600秒，调用方可申请正整数时长；最大默认86400秒、空闲默认600秒，均可通过Hub YAML修改。续租不刷新空闲、不延长已有浏览器会话；状态查询、MCP握手、画面、心跳及幂等重复响应不续命。真实且有界的在途执行暂停空闲，完成后重计，硬期限始终生效。

正常、取消、失败、空闲与确定到期均经统一回收；旧令牌立即停止新执行，清理确认后交接。UNKNOWN不等于COMPLETE，持久QUARANTINED阻止重领。原令牌可查询原租约终态并重复释放，不影响后继租约。停机核查单独留证，原会话UNKNOWN不改写。

Node移除grant/revoke，保留设备身份认证、注册/能力/执行/清理。inspect/session仅作为使用已领取租约的可选诊断。五字段访问文件保持兼容，支持JSON/YAML；Hub自动模式另用hub_url+hub_token认证文件。

真实服务全部使用新临时目录、随机令牌、独立身份及测试站点。浏览器缓存只读复用本机已安装版本；没有复用用户登录Profile。包内版本、安装来源与最终构建提交/SHA256另保存在忽略的local/releases/0.9.1/，发行文件位于两仓库根dist/。
