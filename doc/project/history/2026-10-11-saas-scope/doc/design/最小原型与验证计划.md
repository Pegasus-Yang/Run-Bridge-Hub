# 最小原型与验证计划

[文档导航](../README.md) · [类似产品与开源选型](类似产品与开源选型.md)

本文件是下一阶段可执行的验证提案。本次研究没有运行这些实验，下列数量和阈值属于建议验收标准，不是测试结果。

最新拆分建议见[独立节点服务与对外契约](独立节点服务与对外契约.md)。原型首先增加“无平台参与，普通脚本/CLI 独立查询和使用节点”的验证，并验证原生参数、对象/事件、文件及错误保留；本文件早期平台租户/消息字段用例不要求节点服务继承平台业务模型。

## 1. 原型要证明什么

证明云端 Agent 能在不进入客户内网、不把 AI 规划交付客户的条件下，通过客户节点执行 API/Web/App 动作，并得到足以判断业务结果的证据。另需证明授权撤销、资源冲突和断线时不会错误地标记通过或盲目重复业务写入。

首轮不追求完整 SaaS UI、全部浏览器、设备农场和高并发。用户核心构思中的“复用已登录浏览器”必须在首轮 Web 原型验证，不能用新开浏览器演示替代。

## 2. 阶段与退出条件

| 阶段 | 工作 | 验证与退出条件 |
| --- | --- | --- |
| P0：客户条件确认 | 选一个代表性内网、目标浏览器/手机，明确数据回传与网络政策 | 节点可出站；API/页面可在节点访问；允许最小观测进入平台/模型 |
| P1：最小节点链路 | 登记、认证连接、节点身份、租约、固定工具、命令/结果记录 | 两个测试租户互相不可调度资源；节点可停止；重放/迟到命令受控 |
| P2：API 与 Web 闭环 | 内网 API；独立测试浏览器作为基线；官方扩展复用已有登录 | 云端访问不到被测 URL，节点完成流程；复用原始会话；断言有业务证据 |
| P3：Android | 一台 USB 真机、Appium、UI 树/截图、点击/输入与登录复用 | 调试拒绝/拔线可识别；不清用户数据；设备不被两个任务同时操作 |
| P4：iOS 专项 | 先 Mac 常规路径，再评估非 Mac 受限路径 | 记录 WDA、签名、设备/OS/驱动兼容和观测限制；不复用 Android 的通过结论 |
| P5：产品化 | 安装分发、版本锁定、升级、证据保留、配额与客户引导 | 在选定支持矩阵完成重复运行及故障恢复验证后再扩大范围 |

P0 如果发现必要数据完全不能出网，停止验证纯 SaaS Agent 路线，转而评审有限本地断言或私有 Agent。网络不允许 WebSocket时，先验证获允许的 HTTPS 传输；如果所有平台出站都禁止，换传输不能解决。

## 3. 最小原型建议结构

```text
平台：现有管理 API + 一个异步 Agent Worker + 工具/节点网关
节点：一个常驻客户端 + 本地 HTTP 执行器 + 本地 Playwright/扩展桥接
设备：按阶段添加 Appium 与对应驱动
资料：固定版本、授权记录、动作账本、观测、业务验证和清理记录
```

已有技术栈能承担数据库和异步队列时直接复用，不以“将来可能大规模”作为首轮拆微服务的理由。先用工具 RPC/MCP 证明业务闭环；只有选中的 Agent SDK 明确依赖原生协议时，才增加协议转接原型。

## 4. 核心验收用例

| ID | 场景 | 成功标准/必须观察的事实 |
| --- | --- | --- |
| N01 | 注册节点 | 平台与客户端显示同一租户；配对码不能重复使用；未授权用户不能使用节点 |
| N02 | 两租户隔离 | 跨租户节点 ID、资源 ID、结果和证据请求全部被拒绝 |
| N03 | 资源并发 | 同一手机/浏览器冲突会话只给一个任务租约；另一任务等待或明确失败 |
| N04 | 拒绝或撤销授权 | 节点不执行新动作；平台显示具体待授权/已撤销状态 |
| N05 | 断线/重连 | 查询命令实际状态；丢失返回不能把未确认写入当成功或重新提交 |
| N06 | 取消与旧 Worker | 停止新动作；释放前确认停止；旧租约代次的迟到命令被拒绝 |
| A01 | 内网 API | 从云端不可达、节点可达；状态码、正文和业务状态符合用例 |
| A02 | 私有 CA/mTLS/代理 | 使用客户批准配置成功；错误证书产生可解释失败，未默认关闭校验 |
| A03 | 请求完成后断连 | 查询业务结果或输出 `OUTCOME_UNKNOWN`，不盲目重复写入 |
| W01 | 独立浏览器基线 | 启动位置可确认在节点；账号与测试数据符合预期；断言可重复 |
| W02 | 已登录浏览器复用 | 无重新登录，授权的是原有页面/正确 Profile；业务账号和原有会话保持 |
| W03 | 非授权标签页 | 无法从工具接口读取或控制；新窗口/iframe/跳转遵循既定范围 |
| W04 | 用户手动干预 | 页面变化触发重新观测，不在过期元素/坐标上继续操作 |
| W05 | 文件/弹窗/多标签页 | 上传限定文件，下载位置与回传正确；原有用户页面不被误关闭 |
| W06 | 前台/后台/最小化 | 分状态记录可操作性、等待和截图；不把通信成功当交互成功 |
| M01 | Android 准备 | USB 调试拒绝/未授权可识别；授权后正确选择设备 |
| M02 | Android App 会话 | 登录保留；UI 树/截图/动作和业务结果一致；无意外清数据或重装 |
| M03 | 设备断连/受保护截图 | 明确暂停/失败/观测不足；不生成没有证据的 PASS |
| I01 | iOS 常规路径 | 兼容矩阵、信任、WDA 与会话创建都成功，之后再做业务断言 |
| I02 | iOS 非 Mac 路径 | 按官方限定环境验证，分别记录预装 WDA/外部 WDA 与 RemoteXPC 的结果 |
| S01 | 恶意页面指令 | 页面请求上传本地秘密、改变上传地址/目标服务，确定性策略拒绝 |
| S02 | 数据与日志 | 测试密钥未进入模型输入或常规日志；截图/响应脱敏满足约定 |
| S03 | 清理 | 自建进程/会话回收、授权解除、租约释放；用户浏览器与手机业务数据保留 |

W03 的通过需要验证实际工具过滤和浏览器行为，不仅检查配置有白名单。对于原生 Profile 接入的宽授权模式，应使用专用测试 Profile，不能沿用“只允许一个标签页”的验收声明。

## 5. 结果判定规则

建议固定业务案例：先人工建立预期和测试数据，再运行云端 Agent。订单等写操作使用可追踪业务 ID，测试后通过页面与接口/日志核对实际结果。

| 可观察结果 | 应报告 |
| --- | --- |
| 命令返回成功且业务断言成立 | `PASS`，附相关证据 |
| 驱动动作成功但业务结果不符合 | `FAIL`，动作成功与断言失败分别记录 |
| 权限、断线或观测缺失导致无法判断 | `INCONCLUSIVE`，列出阻断条件 |
| 操作可能已产生写入，无法核对 | 外部效果 `OUTCOME_UNKNOWN`，不直接重跑 |

Agent 自述“完成了”、一张截图、一次成功点击、驱动退出码为 0 都不是完整验收证据。手机测试也不能仅根据 Appium session 创建成功就认定业务用例成功。

## 6. 性能与稳定性验证

建议先对每条已支持主路径做 30 次重复运行，分别统计业务通过、环境失败、模型判断失败、权限等待和未知结果；不要把所有原因混成一个成功率。数量是初步采样方案，不代表对生产可靠性的统计保证。

网络实验可以加入 50/150/500 ms 往返延迟及一次人为断连。记录工具往返的 p50/p95、模型耗时、观测大小、总用时、停止耗时和清理状态。先根据真实用户可接受时长设阈值；避免在没有客户场景数据时承诺固定 SLA。

后台、窗口失焦、最小化、锁屏、休眠和设备锁定分别记录。一个前台用例通过不能说明其余状态可用。长期无人值守还要额外测试客户端运行、升级和设备连接恢复。

## 7. 成本模型和执行粒度

粗略时间模型：

```text
总用时 ≈ 本地业务动作耗时
       + 工具网络往返数 × RTT
       + 各次模型调用耗时
       + 图片/附件传输耗时
       + 排队、准备和人工等待
```

示例仅用于量级说明：若 100 次远程往返、RTT 为 150 ms，网络往返项约为 15 秒；30 张每张 200 KB 的截图约为 6 MB，尚未包含封装、重复上传或录屏。实际截图大小、协议往返数和模型耗时需要测量。

建议把“点击并等待一个明确结果”“填写一个已确定表单”这样的短确定性操作交给本地执行器，而把下一步业务决策留给云端 Agent。批量动作须在目标变化时停止并回传，不能把一个长期开放目标伪装成固定工具。

云端单次成本可按模型调用、Agent Worker 占用、证据存储/下载和连接网关占用估算。浏览器和设备资源由客户提供可降低平台的设备成本，但客户支持、版本兼容和授权准备会增加产品维护投入。本次没有报价或实测成本。

## 8. 进入实施前的决策清单

| 决策 | 建议默认值 | 改变选择的影响 |
| --- | --- | --- |
| 是否允许必要观测进入平台/模型 | 允许已约定最小范围，秘密使用本地引用 | 完全禁止时需要私有 Agent 或削减 AI 分析能力 |
| 目标客户节点 | 交互电脑与专用测试机分别提供模式 | 无人值守能力、权限流程和并发策略不同 |
| Web 首期支持 | Chromium 独立浏览器 + 官方扩展复用 | 任意浏览器/跨平台接管明显扩大验证范围 |
| Agent 工具接口 | 受控 RPC/MCP 工具 | 强依赖 CDP 的 SDK 需要协议适配路线 |
| 断线后的写操作 | 先核对、无法确认则未知 | 盲目重试可能重复创建或提交 |
| 移动范围 | Android 首轮；iOS 分常规/受限路径 | 同步覆盖全部平台增加环境支持成本 |
| 授权与清理 | 本机可停止，保留用户原有资源 | 自动清 Profile/卸载 App 会改变复用场景 |

团队规模、已有平台模块、客户网络和数据政策尚未确定，因此不提供看似精确的工期。原型后根据实际适配量、稳定性和客户准入成本估算实施计划。
