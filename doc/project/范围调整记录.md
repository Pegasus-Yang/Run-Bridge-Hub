## 2026-10-11：确认首期实施基线

用户确认首期采用单 ASGI Worker，并将初期规模收敛为 **100 用户、10 并发执行**。本轮只更新实施基线与验收计划，未开始产品编码。

确定的选择：

- 范围为独立节点管理、节点网关和客户端，不恢复平台与 Agent 的业务范围。
- 标准 Python 3.14.x、Pydantic V2、asyncio；FastAPI/Starlette、Uvicorn 提供管理 API 与网关。
- 管理与网关分模块，同服务、单实例、单 ASGI Worker 部署。
- SQLite 保存节点、访问许可和会话元数据；活连接与即时路由在内存；客户端保存本地身份与配置。首期不引入 Redis 或独立数据库服务器。
- 每节点一条控制连接，执行会话使用独立出站隧道；保留执行工具原生协议与参数。
- 100 用户、10 并发执行作为容量规划与压测目标，每名用户暂按 1 个在线客户端估算；截图/录像等大输出另测。

容量数字是规划与验证目标，未被性能测试证明；完整依赖组合、浏览器原生路由和真机执行同样待验证。详细实施阶段与通过条件以[最小实现与验证计划](../design/最小实现与验证计划.md)为准。
